# PRISMA

**Pensar. Compreender. Aprender.**

O PRISMA é uma plataforma educativa centrada na ligação entre **Currículo ↔ Professor ↔ Aluno**.

## Visão
- apoiar o professor na planificação, criação de recursos e avaliação;
- dar ao aluno um percurso de aprendizagem, prática e verificação;
- usar o currículo como estrutura de referência, não como conteúdo inventado pela IA.

## Estado atual
A versão online apresenta dois espaços — Professor e Aluno — e uma experiência navegável para ambos.

## Próximas fundações
1. integrar as Aprendizagens Essenciais oficiais;
2. separar dados curriculares da interface;
3. criar contas e persistência;
4. ligar tarefas do professor ao percurso do aluno;
5. introduzir feedback adaptativo;
6. preparar uma base segura para o Tutor PRISMA.

## Princípio pedagógico
O PRISMA não deve substituir o professor nem reduzir a aprendizagem a respostas automáticas. A tecnologia deve ajudar a tornar mais visíveis o problema, os conceitos, os argumentos, a prática e o progresso.
